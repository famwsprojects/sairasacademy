SAIRA'S ACADEMY – FIXED WEBSITE PACKAGE

This version embeds the shared CSS and navigation script into each HTML page.
Each page can be opened directly, and the navigation links work when the five
HTML files are kept together in the same folder.

Pages:
index.html – Home
about.html – About Us
tutors.html – Meet Our Tutors
testimonials.html – Tutor Reviews
contact.html – Contact Us

Extract the ZIP before previewing. Open index.html in Chrome, Edge, Firefox or Safari.
For publishing, upload all five HTML files together. No external CSS or JS files
are required by this standalone version.
